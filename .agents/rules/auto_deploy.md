# Auto Deploy Workflow

Whenever you complete a coding task or modify files in this repository that represent a logical chunk of work, you MUST automatically stage, commit, and push the changes to the `main` branch to trigger the live website deployment.

**Steps to follow upon completing edits:**
1. Run `git add .`
2. Run `git commit -m "feat/fix: <brief description of what was changed>"`
3. Run `git push`

Do not wait for the user to explicitly ask you to push the code. Proactively push the code and then inform the user that the changes are being deployed to the live website.
